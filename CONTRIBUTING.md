# Bijdragen

Bedankt voor je bijdrage.

## Werkwijze

1. Maak een aparte branch.
2. Beschrijf het probleem.
3. Voeg een kleine, gerichte wijziging toe.
4. Voeg tests toe.
5. Controleer dat er geen geheimen zijn opgenomen.
6. Open een pull request.
7. Wacht op menselijke beoordeling.

## Niet toegestaan

- ongecontroleerde automatische merges;
- verborgen telemetry;
- malware of misleidende code;
- betaalclaims zonder bewijs;
- opgeslagen tokens of wachtwoorden;
- wijzigingen buiten de afgesproken scope.
