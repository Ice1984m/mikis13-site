# Mikis13 Cyber & Tech Shop

Professionele statische demo-webshop voor:

- gamingaccessoires;
- pc-accessoires;
- reparatiegereedschap;
- privacyproducten;
- digitale handleidingen.

## Veiligheidsstatus

De winkelwagen werkt lokaal in de browser.

Betalingen staan bewust in demomodus. Plaats nooit een geheime Stripe-sleutel
in HTML of JavaScript. Een echte betaalfunctie vereist een beveiligde backend
of een officiële Stripe Checkout-integratie.
