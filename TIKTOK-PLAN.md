# Mikis13 TikTok-plan

## Doel

TikTok wordt gebruikt om geïnteresseerde bezoekers naar de officiële
website en de openbare GitHub-projecten te leiden.

## Veilige start

Plaats gedurende vier weken minstens drie originele video's per week.

### Thema 1 — website bouwen

- Van foutmelding naar werkende GitHub Pages-site
- Wat betekent een rood kruis in GitHub Actions?
- Een eigen domein aan GitHub Pages koppelen

### Thema 2 — Android en Termux

- Een GitHub-repository veilig klonen in Termux
- Waarom API-sleutels nooit in openbare code horen
- Een GitHub Actions-logboek lezen

### Thema 3 — projectontwikkeling

- Voor en na van een websiteverbetering
- Open taken en bijdragen uitleggen
- Een eenvoudige bug oplossen

## Formaat per video

1. Probleem in de eerste twee seconden.
2. Toon één duidelijke oplossing.
3. Toon het resultaat.
4. Eindig met één oproep:
   "Bekijk Mikis13 via de link in mijn profiel."

## Regels

- Gebruik uitsluitend eigen beelden, stem en code.
- Doe geen inkomensgaranties.
- Koop geen volgers, likes of weergaven.
- Zet geen geheime sleutels of persoonsgegevens in beeld.
- Controleer muziek- en beeldrechten vóór publicatie.
- Gebruik eerst organische content voordat geld aan advertenties
  wordt uitgegeven.
