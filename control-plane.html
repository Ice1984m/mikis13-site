CONTROL PLANE

Mikis13 Control Plane brengt mijn websitebeheer, GitHub-workflows, securitycontroles, containers, automatische tests, repair-bots, historiek en releasebeheer samen in één centraal systeem.

TERMUX • GITHUB ACTIONS • AUTOMATION • SECURITY • DEVOPS

🌐 LIVE STATUS

Domeinen, HTTPS, HTTP-status en responstijden automatisch controleren.

🤖 REPAIR BOT

Mislukte workflows herkennen, classificeren en gecontroleerd opnieuw uitvoeren.

🐳 CONTAINERS

Container-builds, GitHub Actions en GHCR vanuit één controlelaag volgen.

🛡 SECURITY

Secret scanning en veiligheidscontroles voordat wijzigingen gepubliceerd worden.

🧪 E2E TESTS

Belangrijke websitepagina's automatisch testen na wijzigingen.

📊 OBSERVABILITY

Statushistoriek bewaren zodat problemen en verbeteringen zichtbaar worden.

🚦 RELEASE GATE

Publiceren alleen wanneer vereiste controles groen zijn.

📦 RELEASES

Versiebeheer, changelogs en GitHub-releases centraal organiseren.

📱 TERMUX CENTER

Eén centraal mobiel commando voor status, testen, repair en beheer.

🧠 DRIFT DETECTOR

Vergelijkt lokale code met GitHub zodat afwijkingen snel zichtbaar worden.
