# Mikis13-beloningen

Een GitHub-label of issue is op zichzelf geen betalingsbelofte.

Een beloning is alleen geldig wanneer de repository-eigenaar vóór de
start schriftelijk bevestigt:

1. het exacte bedrag;
2. de valuta;
3. de oplevercriteria;
4. de uiterste datum;
5. de betaalwijze;
6. wie aan de taak is toegewezen.

Werk zonder deze bevestiging wordt beschouwd als een vrijwillige
bijdrage.

Geheime sleutels, bankgegevens, identiteitsdocumenten en andere
persoonsgegevens mogen nooit via een openbaar issue worden gedeeld.
