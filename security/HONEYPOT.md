# Mikis13 Honeypot

Deze map bevat uitsluitend decoy/lokbestanden.

## Doel

- geautomatiseerde scanners herkennen;
- verdachte verzoeken naar typische gevoelige routes herkennen;
- echte beheerbestanden scheiden van publieke bestanden.

## Belangrijk

Alle credentials in deze repository zijn nepwaarden.

Echte:

- API-sleutels
- wachtwoorden
- tokens
- security logs
- IP-logs

mogen nooit in deze publieke repository worden opgeslagen.

GitHub Pages is statisch.

Realtime detectie en Android-alerts worden uitgevoerd
door de private Mikis13 Node/Termux security-server.
